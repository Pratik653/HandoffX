# Final consolidated research paper

| File | Content |
|---|---|
| `HandoffX_Final_Research_Paper.pdf` | Typeset paper (A4): title page, linked contents, numbered equations (1)–(14), 33 tables, 12 figures, page numbers |
| `HandoffX_Final_Research_Paper.docx` | Word version with native Word equations, heading styles, captions and a table-of-contents field. Word asks to update fields on opening |
| `HandoffX_Final_Research_Paper.md` | Markdown source of record, generated by `build_final.py` |
| `HandoffX_Final_References.bib` | BibTeX for all 35 references |
| `src/` | New text of the paper, with include directives that copy verbatim blocks from the preserved v0.1 and v0.2 manuscripts |
| `build_final.py` | Assembles the Markdown and builds the DOCX and PDF |
| `verify_paper.py` | Checks citations against references, key numbers against stored results, and equation numbering |
| `ZENODO_PREPARATION.md` | Metadata and checklist for a future deposit (not deposited) |

The earlier manuscripts are preserved unchanged as archived versions:
- `01_Publication/` (v0.1, 28 October 2026);
- `publication_v2/` (v0.2, 29 October 2026).

## Rebuild

```bash
python publication_final/build_final.py      # needs python-docx, latex2mathml, lxml, MS Office MML2OMML.XSL, MS Edge
python publication_final/verify_paper.py     # needs only the standard library and the stored results
```

The PDF is printed by headless Microsoft Edge from HTML with MathML; equations and tables were checked visually page by page. The DOCX was generated with python-docx and validated structurally:
- 306 native equations;
- 33 tables;
- 12 images;
- 177 headings;
- a TOC field.

It was not opened in Microsoft Word, because Word automation was unavailable on the build machine, so its pagination and the populated table of contents are unverified.
